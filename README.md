This project involves localizing and classifying surface defects on a steel sheet.
Models used for comparison:
  -  [U-Net](https://lmb.informatik.uni-freiburg.de/people/ronneber/u-net/)
  -  [Mask R-CNN](https://github.com/facebookresearch/maskrcnn-benchmark)
  -  [YOLO](https://docs.ultralytics.com/)
  -  [Sam](https://github.com/facebookresearch/segment-anything)
  -  [ViT](https://github.com/google-research/vision_transformer)
  -  [Dino](https://github.com/facebookresearch/dinov2)

Dataset used:
  - https://www.kaggle.com/competitions/severstal-steel-defect-detection/data
  - https://www.kaggle.com/datasets/kaustubhdikshit/neu-surface-defect-database
  - https://www.vicos.si/resources/kolektorsdd2
